Security reporting

Report security issues without placing sensitive material on a public channel.

URAI Foundation provides a dedicated public security-report address. This static page does not claim a confidential intake portal, incident-response SLA, certification, or protected case-management backend unless those are separately verified.

Safety boundary: Do not send passwords, API keys, session cookies, private keys, recovery codes, protected health information, privileged legal records, or raw vulnerability payloads by email. Send the minimum information needed to request a private follow-up path.

Public boundary

A public reporting route should identify the right destination without pretending sensitive incident handling is public.

Reportable issues

Authorization failures, exposed credentials, accidental public data, unsafe redirects, public configuration mistakes, and other security-sensitive findings can be reported through the security route.

Minimize disclosure

Share the affected public URL and a concise impact description first. Request a private follow-up route before sending proof that contains secrets or personal data.

No certification claim

This page does not represent that URAI Foundation has completed an external security audit, penetration test, legal review, or formal certification unless separately verified.
