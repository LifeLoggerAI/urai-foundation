# URAI Foundation Advisor Kit

This folder is for onboarding a clinical/scientific advisor to URAI Foundation.

## Purpose

URAI Foundation needs a practical, responsible, and easy-to-review operating packet for foundation work, grants, pilots, accessibility, veteran support, caregiver support, memory preservation, and human development.

## Safe framing

URAI is an AI-assisted memory, identity, reflection, accessibility, narrative-continuity, and personal-world platform.

URAI is not being presented as a medical device, diagnosis system, treatment, therapy replacement, or clinical outcome predictor.

## Advisor role

The advisor can help with:

- claims review
- safety language
- pilot design
- measurement framework
- accessibility review
- grant language
- partner credibility
- research pathway
- referral/escalation boundaries
- letter of support
- advisory board recruitment

## Recommended first pilot

Memory Worlds for Seniors / Caregiver Connection Archive.

This pilot can focus on memory preservation, family storytelling, identity continuity, caregiver connection, accessibility, and user-owned life story artifacts.
